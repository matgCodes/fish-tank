# Two-minute video script

Layout: room display full width, door sign in a narrow window beside it.
Press Reset before recording. Press Start replay on the first line.

**0:00 – 0:12, before pressing anything**
"This is Fish Tank. It's an agent that lives in the meeting room, not in a
chat window. This is the room display, and this is the door sign people see
through the glass. We're going to run a four-minute vendor meeting."
Press Start replay.

**0:12 – 0:30, agenda lights up, door goes red**
"The agent knows the agenda and who's in the room. The timer starts, and the
door sign outside flips to in use. Nobody typed anything. It's listening."

**0:30 – 0:50, decision and first action land**
"Sam just said Northwind's support was better. Mat called it: decision made.
Watch the ledger. The decision lands, then the action item lands with Sam's
name and Friday, because Mat said both out loud."

**0:50 – 1:05, agenda advances**
"Mat says let's move on, and the agent moves the agenda. If an item runs long,
the nudge shows up on screen. The agent never talks. It writes."

**1:05 – 1:30, owner? then the correction**
"Here's the part a chatbot can't do. Sam says someone needs to draft the
checklist. No name, so the agent puts owner with a question mark instead of
guessing. Mat says: no, that one's Priya's. Same item, updated in front of
everyone. The room corrected the record before it was a record."

**1:30 – 1:50, wrap, door flips, follow-up proposed**
"That's a wrap. The meeting ended early, so the door sign goes green for
whoever's waiting. The agent proposes a follow-up built only from what the
room agreed to. It doesn't send it. A person does."
Tap Send follow-up.

**1:50 – 2:00, close**
"Every item is one tap to edit or delete, and there's a badge for every
failure state. Built today. Repo's in the description."
